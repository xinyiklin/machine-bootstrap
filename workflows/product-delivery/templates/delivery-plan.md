# Delivery Plan — deprecated

Workflow: `product-delivery` 2.1.0

Since workflow 2.0.0 the Delivery Plan is merged into the living Implementation
Plan. Use `implementation-plan.md` in this directory; do not create new
delivery plans.

An active 1.x plan is consolidated into a new Implementation Plan when its task
resumes and is kept as a historical reference. A plan version the user
approved that was still in force (not superseded or invalidated) remains
authorization for exactly its scope; if that is ambiguous, ask the user.
